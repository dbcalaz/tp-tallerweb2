# Frontend

Aplicación Angular del proyecto Taller Web II.

## Módulos

- src/app/features/users/: registro de usuarios y acceso a la API de usuarios.
- src/app/features/products/: página inicial del catálogo.
- src/app/features/cart/: página inicial del carrito.
- src/app/app.routes.ts: rutas de la aplicación.
- src/app/app.ts: navegación principal y área de páginas.

## Ejecutar

Desde esta carpeta:

    npm install
    npm start

Abrí http://localhost:4200. El proxy de desarrollo reenvía /api al backend en http://localhost:5555.
